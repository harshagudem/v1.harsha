CrashPad Web App Project is a capstone project for my Master’s in Information Systems, developed by a team of four. It simplifies RV parking management with features for booking, space management, and payments. Using Java Spring Boot, MySQL ReactJS, TypeScript, Docker , and AWS, I worked on the front-end. The project followed Agile methodologies for iterative development and continuous feedback.
